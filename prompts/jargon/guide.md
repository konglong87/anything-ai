# 从感觉到执行

## 先选场景，再填参数

1. 在[专业提示词库](./README.md)按领域、类型或关键词查找；可以搜索白话、专业名词和别名。站点导引词仅帮助发现相关条目，不代表固定风格、执行默认或已核验结论。
2. 进入详情，阅读适用场景与警示；填写任务、参考图说明等必要输入。图片必须另外上传到目标 AI，输入框不会自动上传文件。
3. 多风格与工具参数只选一项，预览会同步更新。未填项保留明确占位，不擅自补数据。
4. 点击复制后粘贴到目标工具，核对输入完整，再执行。复制失败时会提供手动复制，不会显示虚假成功。

## 从首页进入与分享搜索

首页可直接输入「简洁大方的后台界面」，或点击示例词和需求捷径，进入后不用重新输入。关键词、领域与类型随网址同步；刷新和浏览器前进后退可恢复条件。点击「复制搜索链接」可分享当前检索，链接不包含组合中的任务目标或参数。搜索词会出现在网址和浏览器历史中，请勿输入敏感信息。顶部「站内搜索」用于找文章与教程，不等于提示词检索。

## 组合不是全库堆叠

- 同一任务可组合同领域的互补模块，最多 8 个。
- 同一互斥方向只能选一项；工具不兼容、待核验研究和未确认执行逻辑不能混入执行组合。
- 组合区可填写统一目标、逐条移除或清空。选择记录仅存在当前浏览器会话，填写的任务文本不持久化，也不上传服务器。
- 分类合集和全库下载保留条目分隔，只是收藏素材，不是要求 AI 同时执行所有模板。

## 原文与整理版

每条内容都有固定提交的来源链接、原始结构化内容与整理后的文字提示。数字与性能参数是原文锚点或示例，不是效果保证；待确认部分必须先澄清。完整规则见[来源与覆盖清单](./sources.md)。

## 无 JavaScript 与无剪贴板权限

页面下方保留分类文字导航；详情的「阅读完整文字版」可展开、选中与手动复制。交互式搜索、填参和组合需要 JavaScript。剪贴板受限时，请手动选中预览文字复制。
