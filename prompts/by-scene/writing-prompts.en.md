# Writing Scenario Prompts

## Article Writing

### Blog Posts

**Use Case**: Quickly generate blog articles

**Prompt Template**:
```
You are a professional blog writer. Please write a blog post about [topic].

Requirements:
1. Target audience: [reader group]
2. Writing style: [style description]
3. Word count: [word count requirement]
4. Key points to include:
   - [point1]
   - [point2]
   - [point3]

Article structure:
1. Engaging title
2. Brief introduction
3. Main content (divided into sections)
4. Conclusion and call to action
```

**Example Input**:
```
You are a professional blog writer. Please write a blog post about "How AI is Changing Software Development".

Requirements:
1. Target audience: Software developers
2. Writing style: Professional, practical, inspiring
3. Word count: 1500-2000 words
4. Key points to include:
   - AI code generation tools
   - Automated code review
   - Test case generation
   - Automated documentation generation

Article structure:
1. Engaging title
2. Brief introduction
3. Main content (divided into sections)
4. Conclusion and call to action
```

**Example Output**:
```
# How AI is Revolutionizing Software Development: From Code Generation to Automated Testing

## Introduction

Software development is undergoing an unprecedented transformation. With the rapid advancement of artificial intelligence technology, AI tools are reshaping how developers work daily. From code generation to automated testing, AI is becoming a capable assistant for developers, greatly improving development efficiency and code quality. This article will explore how AI is changing various aspects of software development and how developers can adapt to this transformation.

## AI Code Generation Tools

### From Assistance to Collaboration

AI code generation tools have evolved from simple code completion to understanding requirements and generating complete features. Tools like GitHub Copilot and Cursor can not only predict code based on context but also understand natural language descriptions and generate code snippets that meet requirements.

### Practical Applications

- **Rapid Prototyping**: AI can quickly generate basic code frameworks, allowing developers to focus on core logic
- **Learning New Technologies**: AI-generated code can serve as a reference for learning new technologies
- **Reducing Repetitive Work**: Common patterns and boilerplate code can be automatically generated by AI

### Best Practices

1. **Understand Generated Code**: Don't blindly copy, understand what every line does
2. **Test and Validate**: Always test AI-generated code
3. **Iterate and Optimize**: Use AI generation as a starting point, optimize based on requirements

## Automated Code Review

### Intelligent Code Review

AI tools can now automatically perform code reviews, identifying potential issues:
- Code style inconsistencies
- Potential performance issues
- Security vulnerabilities
- Best practice violations

### Improving Code Quality

Benefits of automated code review:
- **Instant Feedback**: Discover issues during development
- **Consistency**: Ensure the entire codebase follows unified standards
- **Knowledge Sharing**: AI can learn team best practices

## Test Case Generation

### Automated Testing

AI can automatically generate test cases based on code:
- Unit tests
- Integration tests
- Boundary condition tests

### Improving Test Coverage

AI-generated test cases can:
- Cover scenarios developers might overlook
- Generate boundary condition tests
- Provide diverse test data

## Automated Documentation Generation

### Intelligent Documentation

AI can automatically generate based on code:
- API documentation
- Code comments
- Usage examples

### Keeping Documentation Updated

Automated documentation generation solves the problem of outdated documentation:
- Automatically update documentation when code changes
- Ensure documentation is consistent with code
- Reduce maintenance costs

## Conclusion

AI is fundamentally changing the way software development is done. It's not about replacing developers, but becoming a powerful assistant that allows developers to focus on more valuable work. The key is to learn to collaborate with AI, understand its capabilities and limitations, and establish effective workflows.

### Call to Action

1. **Try AI Tools**: Start with simple code completion, gradually explore more complex applications
2. **Establish Best Practices**: Develop team guidelines for using AI tools
3. **Continuous Learning**: Keep up with the latest developments in AI technology, constantly update skills

The AI era has arrived. Embrace it and let it become your super assistant.
```

**Notes**:
- Adjust language and depth based on target audience
- Add specific examples and data support
- Maintain clear article structure
- Add call to action

**Variation Suggestions**:
- Ask to add code examples
- Ask for detailed introduction of specific tools
- Ask to add FAQ section

## Copywriting

```

- Unique selling points: [selling point list]

1. Highlight product advantages
2. Use compelling language
3. Include call to action
4. Word count: [word count requirement]

Please provide:
1. Short version (for ads)

3. Social media version (for social media)
```

## Title Optimization

### Generate Engaging Titles

**Use Case**: Generate engaging titles for articles or content

**Prompt Template**:
```
Please generate 10 engaging titles for the following content:

[content summary]

Requirements:
1. Title type: [type: question/numbered/suspense etc.]
2. Target platform: [platform: blog/social media/news etc.]
3. Target audience: [reader group]
4. Include keywords: [keyword list]

Please rank by attractiveness and explain the strengths of each title.
```

**Example Input**:
```
Please generate 10 engaging titles for the following content:

Content summary: Introduction to how AI helps developers improve programming efficiency, including code generation, code review, test case generation, etc.

Requirements:
1. Title type: Numbered and question formats
2. Target platform: Technical blog
3. Target audience: Software developers
4. Include keywords: AI, programming, efficiency, developers

Please rank by attractiveness and explain the strengths of each title.
```

**Example Output**:
```
1. "5 AI Tools That Boost Developer Efficiency by 300%"
   - Strength: Specific numbers, clear results, attracts clicks

2. "How Can AI Boost Developer Efficiency by 300%?"
   - Strength: Question format sparks curiosity, specific numbers

3. "5 Must-Have AI Programming Tools for Developers"
   - Strength: Clear target audience, highly practical

4. "Is 300% Efficiency Boost with AI Programming Possible?"
   - Strength: Question format, sparks desire to verify

5. "AI Programming Era: 5 Secrets to Developer Efficiency Boost"
   - Strength: Uses "secrets" to add mystery

6. "From Code Generation to Testing: How AI is Changing Programming"
   - Strength: Comprehensive coverage, professional

7. "Developer Efficiency Revolution: 5 Major AI Applications"
   - Strength: Uses strong words like "revolution"

8. "AI Programming Assistant: Boost Developer Efficiency by 300%"
   - Strength: Directly states topic and results

9. "Why Developers Need AI? 5 Reasons Tell You"
   - Strength: Question format, highly practical

10. "AI Programming: 5 Key Techniques for Efficiency Boost"
    - Strength: Highly practical, provides specific techniques
```

**Notes**:
- Adjust title style based on platform characteristics
- Consider SEO optimization
- Test effectiveness of different titles
- Avoid clickbait

**Variation Suggestions**:
- Ask to generate titles in different styles
- Ask how to optimize title for SEO
- Ask to add subtitles

## Content Optimization

### Polish and Simplify

**Use Case**: Optimize quality and readability of existing content

**Prompt Template**:
```
Please optimize the following content:

[original content]

Optimization goals:
1. [goal1: improve readability/simplify/enhance persuasion etc.]
2. [goal2]
3. [goal3]

Please provide:
1. Optimized content
2. Optimization explanation
3. List of improvements
```

**Example Input**:
```
Please optimize the following content:

Original content:
Artificial intelligence is a technology that makes computers simulate human intelligence. It includes machine learning, deep learning, natural language processing, and many other fields. AI can be applied to many scenarios, such as healthcare, finance, education, etc. AI is developing very fast and will change many industries in the future.

Optimization goals:
1. Improve readability
2. Enhance persuasion
3. Add specific examples

Please provide:
1. Optimized content
2. Optimization explanation
3. List of improvements
```

**Example Output**:
```
Optimized Content:

Artificial Intelligence (AI) is revolutionarily changing our world. Through machine learning, deep learning, and natural language processing, this technology enables computers to simulate human intelligence and perform complex tasks.

AI applications have permeated every field:
- **Healthcare**: AI-assisted diagnostic systems can identify certain diseases more accurately than human doctors
- **Finance**: Algorithmic trading systems can analyze market data in real-time and make better decisions
- **Education**: Personalized learning platforms customize teaching content based on student characteristics

With rapid technology development, AI will continue to reshape every industry. From autonomous vehicles to intelligent assistants, AI is becoming an indispensable part of our daily lives.

Optimization Explanation:
1. Added AI abbreviation to improve readability
2. Changed application scenarios to list format for clarity
3. Added specific examples for each scenario
4. Used stronger verbs and more vivid descriptions
5. Added future outlook to enhance persuasion

Improvements:
- ✅ Clearer structure
- ✅ More specific content
- ✅ More powerful language
- ✅ Richer examples
- ✅ Better logical flow
```

**Notes**:
- Maintain original meaning
- Adjust style based on goals
- Add specific examples for support
- Consider target audience

**Variation Suggestions**:
- Ask to optimize for specific audience
- Ask how to enhance SEO effect
- Ask to add data support
