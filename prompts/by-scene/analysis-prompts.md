# 分析场景提示词

## 数据分析

### 趋势分析

**使用场景**：分析数据趋势和模式

**提示词模板**：
```
请分析以下数据的趋势：

[数据描述或数据]

分析要求：
1. 识别主要趋势
2. 找出异常值
3. 分析原因
4. 预测未来趋势
5. 提供可视化建议

请按以下格式输出：
## 趋势概述
## 主要发现
## 异常分析
## 原因分析
## 未来预测
## 可视化建议
```

**示例输入**：
```
请分析以下数据的趋势：

某公司2023年月度销售额（万元）：
1月：120
2月：115
3月：130
4月：145
5月：150
6月：165
7月：160
8月：175
9月：190
10月：185
11月：200
12月：220

分析要求：
1. 识别主要趋势
2. 找出异常值
3. 分析原因
4. 预测未来趋势
5. 提供可视化建议

请按以下格式输出：
## 趋势概述
## 主要发现
## 异常分析
## 原因分析
## 未来预测
## 可视化建议
```

**示例输出**：
```
## 趋势概述

2023年公司销售额整体呈上升趋势，从1月的120万元增长到12月的220万元，全年增长83.3%。增长趋势相对稳定，但有季节性波动。

## 主要发现

1. **整体增长强劲**
   - 年均增长率约5.2%
   - Q1到Q4增长明显
   - 下半年增长加速

2. **季节性模式**
   - Q1（1-3月）：相对平稳
   - Q2（4-6月）：开始加速
   - Q3（7-9月）：持续增长
   - Q4（10-12月）：达到峰值

3. **关键转折点**
   - 4月开始明显增长（+12.1%）
   - 9月达到190万元新高
   - 12月创全年最高220万元

## 异常分析

1. **2月小幅下降**
   - 从1月120降至2月115（-4.2%）
   - 可能原因：春节假期影响

2. **7月小幅回落**
   - 从6月165降至7月160（-3.0%）
   - 可能原因：季节性调整或市场波动

## 原因分析

1. **市场扩张**
   - 新产品线推出
   - 市场份额增加
   - 客户基础扩大

2. **季节性因素**
   - Q4通常是销售旺季
   - 年底促销活动
   - 预算周期影响

3. **运营优化**
   - 供应链改善
   - 营销策略优化
   - 销售团队扩张

## 未来预测

基于当前趋势，预测2024年：

1. **保守预测**
   - 年增长率：15-20%
   - 年销售额：250-260万元

2. **乐观预测**
   - 年增长率：25-30%
   - 年销售额：270-285万元

3. **关键假设**
   - 市场环境稳定
   - 无重大竞争变化
   - 持续投入营销

## 可视化建议

1. **趋势线图**
   - X轴：月份
   - Y轴：销售额
   - 添加趋势线

2. **季节性分解图**
   - 展示趋势、季节性、残差

3. **同比增长图**
   - 对比2022年同期数据
   - 突出增长模式

4. **预测区间图**
   - 展示预测范围
   - 标注置信区间
```

**注意事项**：
- 提供完整的数据背景
- 说明数据的时间范围
- 考虑外部因素影响
- 验证预测的合理性

**变体建议**：
- 要求对比多组数据
- 询问特定影响因素
- 要求添加数据清洗建议

### 对比分析

**使用场景**：比较不同选项或方案

**提示词模板**：
```
请对比分析以下[选项/方案]：

[选项1描述]
[选项2描述]
[选项3描述]

对比维度：
1. [维度1]
2. [维度2]
3. [维度3]

请提供：
1. 对比表格
2. 优缺点分析
3. 适用场景
4. 推荐建议
```

**示例输入**：
```
请对比分析以下三种云服务提供商：

AWS：
- 市场份额：32%
- 主要优势：服务全面、成熟稳定
- 价格：中等偏高
- 学习曲线：陡峭

Azure：
- 市场份额：23%
- 主要优势：企业集成好
- 价格：中等
- 学习曲线：中等

Google Cloud：
- 市场份额：10%
- 主要优势：AI/ML能力强
- 价格：灵活
- 学习曲线：平缓

对比维度：
1. 成本
2. 功能
3. 易用性
4. 生态系统

请提供：
1. 对比表格
2. 优缺点分析
3. 适用场景
4. 推荐建议
```

**示例输出**：
```
## 对比表格

| 维度 | AWS | Azure | Google Cloud |
|------|-----|-------|--------------|
| 成本 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 功能 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 易用性 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 生态系统 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 优缺点分析

### AWS

**优点**：
- 服务最全面，几乎涵盖所有云服务
- 成熟稳定，可靠性高
- 庞大的社区和生态系统
- 丰富的文档和教程

**缺点**：
- 价格相对较高
- 界面复杂，学习曲线陡峭
- 定价模型复杂

**适用场景**：
- 大型企业
- 需要全面服务的项目
- 对稳定性要求高的场景

### Azure

**优点**：
- 与Microsoft产品集成好
- 企业级支持强大
- 混合云解决方案优秀
- 定价相对透明

**缺点**：
- 某些服务不如AWS成熟
- 生态系统略小
- 文档质量参差不齐

**适用场景**：
- 使用Microsoft技术栈的企业
- 需要混合云解决方案
- 企业级应用

### Google Cloud

**优点**：
- AI/ML能力最强
- 定价灵活，性价比高
- 界面友好，易于使用
- Kubernetes原生支持

**缺点**：
- 市场份额较小
- 某些企业级功能不足
- 生态系统相对较小

**适用场景**：
- AI/ML项目
- Kubernetes应用
- 初创公司

## 推荐建议

### 选择AWS如果：
- 需要最全面的服务
- 企业级应用
- 对稳定性要求极高
- 有充足的预算

### 选择Azure如果：
- 使用Microsoft技术栈
- 需要混合云
- 企业级支持需求强
- 预算适中

### 选择Google Cloud如果：
- AI/ML项目为主
- 使用Kubernetes
- 预算有限
- 追求易用性
```

**注意事项**：
- 提供客观的对比
- 考虑不同场景需求
- 说明数据来源
- 提供具体建议

**变体建议**：
- 要求添加成本计算
- 询问迁移建议
- 要求添加风险评估

## 文本分析

### 情感分析

**使用场景**：分析文本的情感倾向

**提示词模板**：
```
请分析以下文本的情感倾向：

[文本内容]

分析要求：
1. 整体情感（正面/负面/中性）
2. 情感强度（1-10分）
3. 关键情感词
4. 情感变化
5. 情感原因

请按以下格式输出：
## 情感概述
## 情感强度
## 关键情感词
## 情感变化
## 情感原因
```

**示例输入**：
```
请分析以下文本的情感倾向：

"这款产品真的让我很失望。虽然设计很漂亮，但是功能太少了，而且价格还这么贵。客服态度也不好，问个问题半天不回复。本来很期待，现在后悔买了。"

分析要求：
1. 整体情感（正面/负面/中性）
2. 情感强度（1-10分）
3. 关键情感词
4. 情感变化
5. 情感原因

请按以下格式输出：
## 情感概述
## 情感强度
## 关键情感词
## 情感变化
## 情感原因
```

**示例输出**：
```
## 情感概述

整体情感：负面

用户对产品整体非常不满意，虽然承认产品的某些优点（设计），但主要表达的是失望和后悔的情绪。

## 情感强度

情感强度：8/10

情感强度较高，用户使用了强烈的负面词汇（"失望"、"后悔"），表达了明显的不满。

## 关键情感词

负面词：
- 失望
- 功能太少
- 价格贵
- 态度不好
- 后悔

正面词：
- 设计漂亮
- 期待

## 情感变化

情感轨迹：
1. 期待（"本来很期待"）
2. 失望（"让我很失望"）
3. 不满（"功能太少"、"价格贵"、"态度不好"）
4. 后悔（"后悔买了"）

情感从最初的期待转变为失望，最后到后悔，呈现明显的负面趋势。

## 情感原因

1. **功能不足**
   - 用户期望的功能没有实现
   - "功能太少"直接导致失望

2. **价格不合理**
   - 价格与价值不匹配
   - "价格还这么贵"加剧负面情绪

3. **服务体验差**
   - 客服响应慢
   - "态度也不好"影响整体体验

4. **期望与现实差距**
   - "本来很期待"表明用户期望高
   - 实际体验与期望差距大导致失望

## 建议

针对这类负面反馈，建议：
1. 改进客服响应速度
2. 增加产品功能
3. 优化定价策略
4. 管理用户期望
```

**注意事项**：
- 考虑文化差异
- 注意语境和语气
- 分析情感变化
- 提供可行的建议

**变体建议**：
- 要求分析多篇文本
- 询问情感改善建议
- 要求添加情感可视化

### 主题提取

**使用场景**：从文本中提取主要主题

**提示词模板**：
```
请从以下文本中提取主要主题：

[文本内容]

提取要求：
1. 识别3-5个主要主题
2. 每个主题提供关键词
3. 说明主题的重要性
4. 提供主题之间的关系

请按以下格式输出：
## 主要主题
## 主题详情
## 主题关系
```

**示例输入**：
```
请从以下文本中提取主要主题：

"人工智能正在改变各行各业。在医疗领域，AI帮助医生诊断疾病；在金融领域，AI用于风险评估和欺诈检测；在教育领域，AI提供个性化学习。然而，AI也带来挑战，如隐私保护、就业影响和伦理问题。我们需要平衡AI的利弊，制定合适的政策。"

提取要求：
1. 识别3-5个主要主题
2. 每个主题提供关键词
3. 说明主题的重要性
4. 提供主题之间的关系

请按以下格式输出：
## 主要主题
## 主题详情
## 主题关系
```

**示例输出**：
```
## 主要主题

1. AI应用
2. 行业影响
3. 挑战与问题
4. 政策与监管

## 主题详情

### 1. AI应用
**关键词**：诊断、风险评估、欺诈检测、个性化学习

**重要性**：这是文本的核心，展示了AI在不同领域的具体应用，是理解AI价值的基础。

### 2. 行业影响
**关键词**：医疗、金融、教育、各行各业

**重要性**：说明AI影响的广度，强调其变革性作用。

### 3. 挑战与问题
**关键词**：隐私保护、就业影响、伦理问题

**重要性**：平衡AI的积极影响，提醒读者关注潜在风险。

### 4. 政策与监管
**关键词**：平衡、利弊、政策

**重要性**：提供解决方案，引导读者思考如何应对AI挑战。

## 主题关系

```
AI应用 ──→ 行业影响
    │
    ├──→ 挑战与问题 ──→ 政策与监管
    │
    └──→ (同时带来机遇和挑战)
```

**关系说明**：

1. **AI应用 → 行业影响**
   - AI的具体应用直接导致行业变革
   - 不同行业应用程度不同

2. **AI应用 → 挑战与问题**
   - AI应用带来便利的同时也产生问题
   - 应用越广泛，挑战越明显

3. **挑战与问题 → 政策与监管**
   - 问题需要通过政策和监管解决
   - 政策旨在平衡AI的利弊

4. **整体关系**
   - AI应用是起点
   - 行业影响和挑战是并行结果
   - 政策监管是应对措施
```

**注意事项**：
- 提取的主题要全面
- 关键词要准确
- 说明主题重要性
- 清晰展示主题关系

**变体建议**：
- 要求提取更多主题
- 询问主题的权重
- 要求添加主题可视化

## 总结

分析场景提示词可以帮助你：

**核心场景**：
- ✅ 数据分析：趋势分析、对比分析
- ✅ 文本分析：情感分析、主题提取

**最佳实践**：
1. 提供完整的数据或文本
2. 明确分析要求和维度
3. 要求结构化的输出格式
4. 验证分析结果
5. 建立自己的分析框架

**记住**：
- 分析结果需要人工验证
- 考虑多角度分析
- 结合领域知识
- 持续优化分析方法
