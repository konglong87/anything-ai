## 🎨 AI绘画与图像生成

### 图像生成工具

**Midjourney**
- 艺术性强、社区活跃
- 适合：创意配图、艺术创作
- 价格：$10+/月

**DALL-E 3**
- 质量高、易用
- 适合：快速配图、商业应用
- 价格：按使用付费

**Stable Diffusion**
- 开源、可定制
- 适合：定制化需求、批量生成
- 价格：免费

**Leonardo AI**
- 功能多、易用
- 适合：快速原型、多种风格
- 价格：免费+付费

### 图像生成技巧

**提示词写作**
```
[主体] [风格] [细节] [质量词]
```

**常用提示词**
- 风格：photorealistic, illustration, anime, digital art
- 质量：masterpiece, best quality, high quality, 4k, 8k
- 光影：cinematic lighting, dramatic lighting, soft lighting

**应用场景**
1. 文章配图
   - 根据内容生成相关图片
   - 保持风格统一
   - 优化图文搭配

2. 封面设计
   - 生成吸引人的封面图
   - 突出主题
   - 符合平台规范

3. 社交媒体
   - 生成平台适配的图片
   - 多尺寸生成
   - 保持品牌风格

### 视频素材生成

**Pika Labs**
