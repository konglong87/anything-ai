# 🏢 职场生存技能

> **在混乱中清醒，在草台班子中反利用——职场人的自我保护与价值提取术**

## 📚 内容索引

- [草台班子反利用指南](./workplace-survival-guide.md) - 普通打工人如何在混乱组织中实现反利用 ⭐ 推荐

## 🎯 适用场景

- ✅ 身处流程混乱、管理不成熟的公司
- ✅ 责任心强但总被耗干的职场人
- ✅ 想在混乱环境中提取经验、增长市场价值
- ❌ 不适用：成熟组织中按流程运转的岗位

## 💡 核心原则

1. **切割资产**——守住边界，不替系统还债
2. **降级交付**——诚实 MVP，不用命硬扛
3. **重塑指标**——用市场价值衡量自己，不用公司 KPI 定义成败
