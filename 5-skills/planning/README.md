# 规划与组织类Skills

本目录收集了规划和组织类的AI Skills，帮助你：

- 跟踪项目进度

## 💡 使用建议

1. **选择合适的Skill**
   - 根据项目类型选择
   - 考虑团队规模
   - 评估功能需求

2. **配置和定制**
   - 根据需求调整设置
   - 创建自定义模板
   - 集成现有工具

3. **最佳实践**
   - 定期更新计划
   - 跟踪进度变化
   - 及时调整策略
