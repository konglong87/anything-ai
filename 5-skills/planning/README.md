## 💡 使用建议

### 选择合适的Skill

**项目管理场景**：
- 任务分解 → Planning with Files
- 进度跟踪 → 定期更新任务状态
- 团队协作 → 共享任务文件

**个人开发场景**：
- 学习规划 → 分解学习路径
- 日常任务 → 管理待办事项
- 目标追踪 → 记录里程碑

**文档整理场景**：
- 文档结构 → 规划文档层次
- 内容组织 → 分类管理文件
- 版本管理 → 追踪文档变更

### 配置和定制

**Planning with Files配置**：
1. 创建项目文件夹结构
2. 定义任务模板格式
3. 设置进度追踪机制
4. 集成版本控制系统

**自定义模板**：
- 任务模板：目标、步骤、截止日期
- 项目模板：阶段、里程碑、验收标准
- 日志模板：日期、进展、问题、计划

### 最佳实践

**定期更新计划**：
- 每日更新任务状态
- 每周回顾项目进度
- 每月总结经验教训

**跟踪进度变化**：
- 使用进度条或百分比
- 记录关键节点
- 标记风险和问题

**及时调整策略**：
- 识别延迟风险
- 调整资源分配
- 优化工作流程

- 项目规划准确率 **85%**
