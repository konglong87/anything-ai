## 📖 简介

**AI-Research-SKILLs** 是一个专为学术研究和深度分析设计的Claude Skill，帮助你：
- 进行高效的文献检索和分析
- 生成研究论文的各个部分
- 辅助数据分析和可视化
- 创建研究计划和实验设计

## ✨ 核心功能

### 1. 文献分析
- 快速总结论文要点
- 提取关键信息和结论
- 比较多篇论文的异同
- 生成文献综述

### 2. 论文写作
- 生成论文大纲
- 撰写各个章节
- 改进语言表达
- 优化论文结构

### 3. 数据分析
- 分析实验数据
- 创建可视化图表
- 解释统计结果
- 生成分析报告

### 4. 研究规划
- 设计实验方案
- 制定研究计划
- 识别研究缺口
- 提出创新点

## 🚀 安装教程

### 前置要求
- Claude账户（推荐Pro版本以获得更好的效果）
- 基本的学术研究知识
- 熟悉你的研究领域

### 安装步骤

#### 方法1：通过Claude直接使用

1. **打开Claude**
   - 访问 [Claude官网](https://claude.ai)
   - 登录你的账户

2. **创建新的对话**
   - 点击"New Chat"
   - 输入以下系统提示词：

```
你是一个专业的学术研究助手，擅长各个领域的研究工作。你的职责是：
1. 帮助用户进行文献检索和分析
2. 辅助撰写学术论文
3. 提供数据分析支持
4. 协助设计实验和研究方案

在回答时：
- 提供准确、可靠的信息
- 引用可靠的来源
- 保持客观和批判性思维
- 遵循学术规范

你应该避免：
- 编造文献或数据
- 提供未经证实的信息
- 忽视学术诚信
- 偏向某一观点

特别注意：
- 当你不确定时，明确说明而不是猜测
- 对于引用的文献，尽可能提供完整的引用信息
- 保持学术写作的严谨性和专业性
```

3. **开始使用**
   - 告诉Claude你的研究领域和需求
   - 让它帮助你进行研究工作
   - 使用它提供的分析和建议

## 💬 常见问题

### Q1: 这个Skill适合所有研究领域吗？

A: 适合大多数研究领域，但对于高度专业化的领域（如医学、法律），建议结合领域专家的意见。

### Q2: AI生成的论文可以直接使用吗？

A: 不建议直接使用。AI生成的内容应该作为参考和灵感来源，需要你进行修改、验证和完善。

### Q3: 如何确保引用的准确性？

A: 建议使用文献管理软件，并亲自验证所有引用的文献。AI可能会产生幻觉，编造不存在的文献。

### Q4: 如何提高研究效率？

A: 建议从以下方面入手：
1. 明确研究目标和问题
2. 建立系统的工作流程
3. 合理使用AI工具
4. 定期回顾和调整计划
5. 保持良好的记录习惯
