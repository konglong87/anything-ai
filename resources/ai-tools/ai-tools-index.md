# AI工具索引

本目录包含了各类AI工具的详细使用指南，帮助你快速找到适合的工具。

## 🤖 对话类工具

### [ChatGPT](./chatgpt/README.md)
- OpenAI开发的对话AI
- 适合：日常对话、内容创作、编程辅助
- 价格：免费+付费

### [Claude](./claude/README.md)
- Anthropic开发的对话AI
- 适合：长文档分析、复杂推理、编程辅助
- 价格：免费+付费

### [DeepSeek](./deepseek/README.md)
- 国产对话AI
- 适合：中文场景、日常使用、成本敏感
- 价格：免费+付费

### [豆包](./doubao/README.md)
- 字节跳动开发的对话AI
- 适合：日常对话、简单任务、免费使用
- 价格：免费

## 💻 编程辅助工具

### [GitHub Copilot](./copilot/README.md)
